# BLH
top down 2d bullet heaven game built with godot, fight waves with cool itemizations systems and abilities.


**Features**
--------------------------
**Moba style shop & Inventory System**
*Features a classic 6 slot inventory system with a stat stacking and recipe components
**Cheat mode: Toggleable mode that grants infinite gold and unlimited slot for testing**
**In game economy management**
**Full Settings Menu:** Keybindings, screen modes (Fullscreen/Windowed/Borderless), volume controls, and VSync.



## 📂 Project Structure

```
├── assets/          # Sprites, VFX, and Audio files
├── gdscripts/       # GDScript files (Player, Gun, Enemy, UI logic)
├── tscnfiles/       # Godot Scene files (.tscn)
└── project.godot    # Main Godot project configuration

```
